3. PyInstallerビルド手順（onedir + pyproj）
3.1 前提
仮想環境推奨
pyprojインストール済
3.2 必要確認

pyprojデータ位置確認：
python -c "import pyproj; print(pyproj.datadir.get_data_dir())"


3.3 ディレクトリ構成
project/
 ├─ main.py
 ├─ ini/
 └─ build/

3.4 ビルドコマンド（基本）
pyinstaller main.py ^
  --name gpx2csv ^
  --onedir ^
  --noconsole ^
  --add-data "C:\path\to\proj;proj"
※Windowsなので ; 区切り


3.5 実行時設定（必須）

アプリ起動時：
import os
import sys

def setup_proj():
    if hasattr(sys, '_MEIPASS'):
        base = sys._MEIPASS
    else:
        base = os.path.dirname(__file__)

    proj_path = os.path.join(base, "proj")
    os.environ["PROJ_LIB"] = proj_path

3.6 hidden-import（必要な場合）
--hidden-import pyproj
--hidden-import pyproj.datadir
